# 器件模型

## 统一约定

- 光用相干复振幅表示：`a = A * exp(j*phi)`，`j` 为虚数单位；功率 `P = |a|^2`，相位单位为弧度。
- 所有损耗以 **dB** 给出且必须**非负**（不允许“负损耗/增益”，越界即拒绝）。
  由 dB 到幅度透射系数的换算固定为：

  ```
  t_loss = 10^(-loss_db / 20)
  ```

  即损耗器件的输出场 = 理想输出场 × `t_loss`；功率透射率为 `10^(-loss_db/10)`。
- 器件只在输入/输出端口之间散射，不存在内部反射通道。

## splitter（2×2 分束器）

参数：

| 参数 | 必填 | 默认 | 取值范围 |
| --- | --- | --- | --- |
| `coupling_ratio` | 否 | `0.5` | `[0,1]`，进入交叉端口 `out1` 的功率比例 k |
| `excess_loss_db` | 否 | `0` | 有限且 ≥ 0 |

散射矩阵（输入顺序 `in0,in1`，输出顺序 `out0,out1`）：

```
S = [[t, j*r],
     [j*r, t]] * t_loss,   t = sqrt(1-k), r = sqrt(k)
```

约定：

- 直通臂（`in0→out0`、`in1→out1`）无附加相位；交叉臂（`in0→out1`、`in1→out0`）固定带 `+π/2` 相位。
  该约定是确定的物理惯例（定向耦合器幺正矩阵），单端注入 50/50 分束器时两输出功率各一半、交叉端相位超前直通端 π/2。
- `excess_loss_db` 作为公共幅度因子作用在两个输出上，不改变分束比。

## waveguide（波导）

参数：

| 参数 | 必填 | 默认 | 取值范围 |
| --- | --- | --- | --- |
| `length_m` | 是 | — | 有限且 > 0（米） |
| `neff` | 是 | — | 有限数（有效折射率） |
| `loss_db_per_m` | 否 | `0` | 有限且 ≥ 0 |

传输关系：

```
phi = 2*pi * neff * L / lambda
out = in * 10^(-loss_db_per_m * L / 20) * exp(j*phi)
```

波长 `lambda` 由仿真运行参数给出（纳米，内部换算为米）。相位是波长的确定性函数，因此波长扫描结果可复现。

## phaseshifter（移相器）

参数：

| 参数 | 必填 | 默认 | 取值范围 |
| --- | --- | --- | --- |
| `phase_rad` | 否 | `0` | 有限数（弧度，任意实数） |
| `insertion_loss_db` | 否 | `0` | 有限且 ≥ 0 |

传输关系：

```
out = in * 10^(-insertion_loss_db / 20) * exp(j*phase_rad)
```

`phase_rad` 即施加的相位偏置，直接叠加到通过场的相位上；与波长无关（热移相等导致的波长相关相位请显式建模为多个扫描点）。

## 相位输出约定

- 每个外部输出端口报告绝对相位（该复振幅的辐角，范围 `[-π,π)`）。
- 零场（功率为 0）相位无定义，结果中以 `phase_valid=false` 标示，不编造相位。
- 比较两输出端口的相对相位时用 `optics.RelativePhase(a, ref)`（库函数）或解析解直接比较。
