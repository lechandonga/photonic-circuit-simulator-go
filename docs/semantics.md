# 容差、确定性与并发语义

## 能量守恒与容差

- 守恒只针对**理想无损耗**光路（所有损耗参数为 0）。
- 判定函数：`engine.AssertEnergyConserved(result, absTol, relTol)`。
  当且仅当

  ```
  |P_in - P_out| <= absTol  或  |P_in - P_out| / P_in <= relTol
  ```

  时判为守恒通过（绝对、相对两个条件满足其一即可，避免大/小功率两个极端误判）。
- 测试与 CLI 对照使用的默认容差为 `1e-12`（`engine.DefaultTolerance`）。在当前实现（标准库 `complex128`）下，
  理想 MZI 全相位扫描的实测绝对误差约为 1e-16 量级，远小于该容差。
- 含损耗光路不要求守恒；总输出功率严格小于输入功率，且各路径功率可按
  `10^(-loss_db/10)` 的固定规则解析核算，测试中有手算对照。

## 解析解对照

- 50/50 分束器单端注入：`P(out0)=P(out1)=0.5`，`arg(out1)-arg(out0)=π/2`。
- 理想对称 MZI（两臂相位差 Δφ，上臂移相、单端从 in0 注入）：

  ```
  P(bar,   out0) = sin²(Δφ/2) = (1 - cos Δφ)/2
  P(cross, out1) = cos²(Δφ/2) = (1 + cos Δφ)/2
  ```

  单元测试对 Δφ ∈ {0, π/4, π/2, π, 3π/2, 2π} 逐点核对，误差阈值 1e-12。

## 确定性与可复现

- 编译：拓扑排序的初始队列与后继展开都按器件 id 排序；外部输入/输出顺序按网表声明顺序。
  同一份网表重复编译、重复仿真结果一致。
- 仿真：`Circuit` 编译后不可变；`engine.Run` 与 `Circuit.Propagate` 只使用局部状态，
  不写任何共享字段，因此同一光路可被多个 goroutine 无锁并发调用。
- 扫描：结果切片按扫描点下标排序返回；浮点运算顺序由拓扑序固定，同一批扫描重复执行逐点一致。

## 批量扫描语义

- 每个扫描点 = 基础网表 + 参数覆盖（`deviceID.paramName → 数值`）+ 波长 + 外部激励。
  覆盖通过重新生成该点专属的网表 JSON 再走同一套严格编译校验完成；覆盖不存在的器件、
  同一点内重复覆盖同一参数、越界值都会让**该点**失败。
- 并发：默认每点一个 goroutine，受 `workers` 信号量限制；单点 panic/错误被捕获进
  `PointResult.Error`（错误信息包含扫描点索引与名称），不影响其它点。
- 隔离：缓存 key 为“原始网表 + 排序后的全部覆盖项（%.17g 精度）”，
  只有覆盖集合完全相同的点才共享编译结果；不同参数点不可能命中同一项。
  缓存本身用互斥保护，`-race` 下验证安全。
- 取消：传入可取消的 `context.Context`；取消后尚未取得执行令牌或已排队的点标记为
  `context.Canceled`，已完成的成功结果与已明确的失败结果原样保留，整体自洽；
  `Result.Canceled` 标示该批是否经历取消，`Completed` 统计产出点数。

## 本地验证方法

```bash
CGO_ENABLED=1 go test -race -v ./...
```

测试覆盖的业务：

- 器件解析解：分束器分束比/固有相位、波导相位与损耗、移相器相位叠加与插损。
- 理想光路：MZI 相位扫描解析解、能量守恒与 1e-12 容差、双端注入。
- 含损耗光路：分束器额外损耗、波导分布损耗、移相器插损的手算功率对照。
- 非法网表：11 类原因码逐一给出可区分拒绝。
- 并发扫描：48 点并发与重复运行一致、点间隔离、单点失败定位、取消自洽、多批次共享缓存竞态安全。
